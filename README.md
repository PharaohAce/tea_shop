# 隆福茶业静态主页

打开 dist/index.html 即可本地浏览。无安装、无外部字体、无第三方脚本、无表单或访问统计。三个图片文件均来自提供的照片。点击海报可打开原图。

## GitHub Pages 发布

将本目录的内容（包括 .github 文件夹与 dist 文件夹）上传到你选择的 GitHub 仓库根目录，使用 main 分支。在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions。推送后，Actions 中的 Publish tea homepage 会发布 dist。发布地址见成功运行的部署结果。相对资源链接兼容仓库子路径。

目前只制作了本地文件和发布流程，尚未关联 GitHub 仓库、推送或上线。需要提供目标仓库地址及可用的 GitHub 登录授权；不需要把密码或访问令牌发送到聊天中。

## 上线前请提供或确认

1. 品牌：确认招牌“隆福茶業”的正式写法；提供透明背景 LOGO（SVG 或 PNG）。
2. 公开到店信息：具体门店地址、地图位置、营业时间、是否接受预约及品茶收费方式。
3. 公开联系方式：门店电话、商用微信/企业微信二维码、公众号或小程序链接。优先使用专门的业务联系方式；无需身份证、家庭地址或账号密码。
4. 产品：确认“冰岛枞韵”名称；正式茶类、执行标准、生产者、产地细分、年份、净含量、包装规格、价格、库存、配送范围、保存方式与保质期。
5. 工艺与来源：确认单丛工艺的实际应用环节。海报中“百年以上”“核心产区”“头春”“非遗级”等表述需要相应资料支持，当前未作为独立宣传承诺使用。
6. 品饮：提供此款茶经过实际验证的投茶量、水温、器具容量与出汤时间；目前未编造统一冲泡参数。
7. 交易入口：如需售卖，提供现有商城/小程序链接及配送售后规则，当前主页没有购物车、收款或预约提交功能。

## 最值得补拍的图片

- 干茶近景、冲泡后的叶底和真实茶汤各 1–2 张，自然光、无滤镜。
- 产品包装正面、背面标签、礼盒与规格对比。
- 门头与门牌照片，便于顾客找店；一张整洁茶席横图（建议宽 2000 像素以上）。
- 真实采摘、做青、杀青、炭焙现场图，注明地点与工序，确保有使用权。
- 当前两张海报照片存在透视、裁切和反光，建议提供海报设计原图。网页将其标明为海报，不冒充真实产品摄影。
